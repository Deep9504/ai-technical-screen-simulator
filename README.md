# AI Technical Screen Simulator 🤖
Live Demo: [Try the AI Interviewer Here](https://ai-technical-screen-simulator.vercel.app/)

A full-stack web application designed to simulate real-world technical engineering interviews. Built with React and Node.js, this platform uses the Google Gemini AI to conduct dynamic, conversational technical screens, evaluate candidate responses, and provide immediate, constructive feedback.

## 🚀 Features
* **Stateful AI Conversations**: Engineered complex state management to pass continuous chat history to the AI, allowing for follow-up questions and contextual memory.
* **Strict Persona Prompting**: Utilized system-level instructions to constrain the AI to a "Senior Engineering Interviewer" persona, preventing it from giving away answers prematurely.
* **Enterprise UI**: Designed a clean, responsive chat interface using Ant Design (antd) components.
* **Real-time API Integration**: Securely bridged a React frontend to the Google Gemini generative AI model via an Express.js backend.

## 🛠️ Tech Stack
* **Frontend**: React.js, Vite, Ant Design (antd)
* **Backend**: Node.js, Express.js, CORS
* **AI / API**: Google Gemini API (@google/genai)
